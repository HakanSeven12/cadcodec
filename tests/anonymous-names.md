# Anonymous block names fixture

`anonymous-names.dwg` is a synthetic AutoCAD 2025 drawing generated by
`BlockNamesFixtures.cs`; it contains no customer content. It has five block
definitions, each with one attributed insertion, alternating named and bare
anonymous definitions. AutoCAD reports the names `NamedBefore`, `*U2`,
`NamedBetween`, `*U4`, and `*U5` for handles 78, 7F, 86, 8D, and 94 respectively.

To regenerate, compile the C# source against AutoCAD's managed assemblies,
set `READTRUTH_OUT` to an output text-file path, NETLOAD the assembly and run
`MAKEBLOCKNAMESFIXTURE` in AutoCAD/Core Console. The drawing is saved next to
that output file. Regeneration on another AutoCAD version may assign different
handles; update the fixture assertions after independently checking the result.

The Rust integration test needs neither AutoCAD nor Indium. The separate unit
test covers non-handle table order, dangling entries, explicit suffixes and
missing control data.
